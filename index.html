Data storage

Fill-ups and pump photos are stored in this browser using IndexedDB. They are not uploaded to GitHub or a server. Export a backup periodically, especially before changing phones or clearing site data.

Location

Location is requested only when you add a fill-up or press Locate. GPS coordinates remain on this device; Fuel Log does not send them to a reverse-geocoding or map service.

OCR

The scanner recognises common Irish/European pump layouts and checks that total ≈ litres × unit price before accepting a value.

Privacy

Personal data stays on this device. Pump photos, GPS coordinates, fill-up history, odometer values and notes are never sent to GitHub by this app. The public GitHub Pages site contains only the application code.

Reset

Delete all locally stored fill-ups from this browser. Export a backup first if you may need them later.
